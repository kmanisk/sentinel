# Collaboration Workflow

This document describes how contributors should coordinate a shared Sentinel change before it is merged.

1. Work on a dedicated branch.
2. Keep each contribution small enough to review independently.
3. Test the affected monitoring or deployment path before merge.
4. Credit co-authors only when they materially contributed to the resulting commit.

## Shared-change handoff

Before merging a change with multiple contributors, make sure the branch contains each person's actual contribution, the final commit message credits co-authors accurately, and the PR description explains what was jointly changed.
